# CosmoVital — ملف المشروع

منصة ويب لمتابعة القياسات الصحية أثناء سيناريوهات الرحلات الفضائية، مستوحاة من تحدي NASA Space Apps الخاص بمتابعة صحة رواد الفضاء. المشروع مستقل ولا يدّعي اعتماد NASA أو استخدام سجل طبي حي لرائد فضاء.

## التشغيل

من جذر المشروع شغّل:

```sh
python -m http.server 8080 --directory dist
```

ثم افتح http://localhost:8080. يحتاج العرض عبر خادم HTTP محلي بدلاً من فتح الملف مباشرة. للاتصال الآمن والنشر استخدم HTTPS. الواجهة قابلة للاستخدام على الهاتف والحاسوب. بعد أول تحميل ناجح يمكن استخدام ملفات الواجهة المخزنة مؤقتًا دون اتصال عندما يدعم المتصفح Service Worker.

## البيانات الحقيقية وحدودها

- القياسات الشخصية تُدخل يدويًا أو تُستورد من ملف. يعرض التطبيق مصدرها وتوقيتها؛ لا يُقدّم الإدخال اليدوي باعتباره قياسًا موثّقًا من جهاز.
- المراجع العلمية عن مخاطر الفضاء مستقاة من المصادر الأصلية المرتبطة داخل واجهة البحث.
- أي بيانات سريرية عامة من الأرض في قسم البحث مفصولة عن سجل المستخدم وعن بيانات رواد الفضاء. لا يجوز استخدامها لتشخيص رائد فضاء أو ادّعاء أنها جُمعت في المدار.
- لا يوجد في هذه النسخة اتصال مباشر بساعة أو حساس أو قاعدة بيانات طبية سحابية.
- التنبيهات مؤشرات للمراجعة وفق مراجع عامة، وليست تشخيصًا طبيًا أو بروتوكول علاج معتمدًا للفضاء. القرارات الطبية أثناء المهمة تخضع لطبيب الرحلة وبروتوكولها.

## استخدام الواجهة

1. افتح لوحة المتابعة وأضف قياسًا، مع اختيار توقيته وسياق القياس.
2. راجع المؤشرات والمخططات، وميّز القياسات الأحدث عن القديمة.
3. استخدم خريطة الجسم لاستكشاف مؤشرات الصحة ومخاطر الرحلة ذات الصلة.
4. راجع التنبيهات والإرشادات، وأكمل المهام اليومية المقترحة.
5. صدّر نسخة من السجل أو تقريرًا قبل نقل الجهاز أو مسح بيانات المتصفح.
6. استورد CSV أو JSON وفق قالب التطبيق؛ الملف غير الصحيح يُرفض دون دمج جزئي.

## الخصوصية والحفظ

سجل القياسات محفوظ محليًا في مساحة تخزين المتصفح، وليس في قاعدة بيانات مركزية. حيازة رابط الموقع لا تعني مشاركة القياسات. حذف بيانات الموقع أو استخدام نافذة خاصة قد يؤدي إلى فقدان البيانات؛ احتفظ بنسخة تصدير عند الحاجة. لا تخزن معلومات تعريفية حساسة على جهاز مشترك، ولا تعتبر التخزين المحلي نظام سجلات طبية محميًا.

## ربط المشروع بالتحدي

| مطلب التحدي | تطبيقه في CosmoVital |
|---|---|
| تجميع مؤشرات الصحة | إدخال قياسات يدوية واستيراد ملفات محددة الوحدات والتوقيت |
| التقييم البصري | بطاقات مؤشرات ورسوم اتجاهات وخريطة جسم تفاعلية |
| التغير عبر الزمن | سجل قياسات قابل للتصفية والمقارنة |
| إجراءات داعمة للصحة | مهام يومية وإرشادات قياس ومراجعة |
| فهم مخاطر الفضاء | مراجع NASA وبرنامج البحوث البشرية |
| تفسير مصدر البيانات | فصل السجل الشخصي عن البيانات البحثية العامة |

## مكونات التسليم

- `dist/`: الموقع الجاهز للنشر.
- `docs/`: توثيق المشروع.
- `tests/`: اختبارات التحقق من منطق البيانات.
- `original/`: النسخة الأصلية المرفوعة محفوظة للمراجعة والتتبع.

## تطوير لاحق للاستخدام الطبي المؤسسي

إضافة حساسات معتمدة تتطلب توثيق الأجهزة والوحدات والتوقيت وجودة الإشارة. استخدام طبي مؤسسي يتطلب مراجعة سريرية وتحققًا من التنبيهات وإدارة وصول وتشفيرًا وسجل تدقيق ونسخًا احتياطية. هذه خطوات تطوير لاحقة وليست قدرات يدعيها هذا الإصدار.
